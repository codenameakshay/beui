# Agent change videos

All 19 routes carry a new badge in the parent audit. This index covers those routes, not only newly added files. Only Voice Orb is a newly added widget file in the branch diff. Each source-backed route has a labeled derivative of its pristine before and final after videos. The source videos remain separate in [recordings.md](recordings.md). Full state gaps remain in [GAPS.md](GAPS.md).

The annotations describe implemented changes or explicitly state that no owned repair exists. They do not imply the displayed idle recording exercises a repaired transition. Native recordings are 25 FPS and unsynchronized. The derived videos preserve input frames without interpolation and add a 112px text header. They do not certify parity.

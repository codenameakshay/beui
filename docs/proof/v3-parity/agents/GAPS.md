# Agent route verdicts and next repairs

No route has exact visual or interaction parity certification. This report separates observed source differences from missing evidence. An unverified state is not an invented defect.

The full state and part inventory is in `route-inventory.json`. It includes the parent's common `rest`, `hover-exit`, `keyboard`, and `reduced-motion` obligations, every named scenario, and every registered source example. The source revision is `a76e57c9bbc2837e96420b2610e9c82a3271bb05`. The live deployment revision is unknown.

## Shared evidence gaps

All 18 source-backed routes have original reference, before, and repaired final recordings. Paths and native FFprobe metadata are in `recordings.md` and `recordings.json`. Those recordings do not prove all states. The automatic pointer moves cross viewport coordinates rather than route-specific semantic targets. The initial source and candidate states are not event-synchronized. Most routes lack matched widget crops, pixel differences, and independent temporal review. Native 25 FPS is below the required 60 FPS for fast text and springs.

Light and reduced-motion source/candidate captures exist only for Voice Orb. The Voice Orb mobile capture uses 390 by 844 pixels. Most other routes still owe light, mobile, effective reduced-motion measurements, and complete keyboard traversal. No generic hover movement certifies action reveal or exit. Named examples remain separate obligations, even where a candidate combines specimens on one route.

## Parent-owned changes

Candidate-only specimens can remain useful, but cannot be combined with a source preview and then counted as matching that source composition. Shared catalog, example selection, shell, and theme changes remain with the parent. This slice made no changes to those files.

True provider favicons need a web-compatible asset plan that preserves the source URLs and fallback behavior. This slice did not replace them with invented brand art or weaken image comparisons. Any shared asset declaration belongs to the parent.

The nine baseline-failing goldens need an independent font, renderer, or comparator investigation. Their unchanged baseline reproduction is not a reason to regenerate them during these fixes.
